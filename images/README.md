# Images

Drop photos here, then swap out the `.photo-placeholder` divs in `index.html` for real `<img>` tags, e.g.:

```html
<img src="images/band-photo.jpg" alt="Pink Lady Slipper" />
```

Suggested files:
- `band-photo.jpg` — About section
- `release-1.jpg`, `release-2.jpg`, `release-3.jpg` — Music section cover art
- `gallery-1.jpg` ... `gallery-6.jpg` — Gallery section

# Pink Lady Slipper — Website

Basic single-page site: Home, About, Music, Tour, Gallery, Contact.

## Run locally

```bash
cd pinkladyslipper
python3 -m http.server 8000
# open http://localhost:8000
```

Or just open `index.html` directly in a browser.
